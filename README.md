# Premier League Market Value Predictor

CSCI 399 Independent Study project focused on Data Analytics, Machine Learning, and AWS.

## Project Goal

Build a machine learning model that predicts Premier League player market values using player performance statistics.

The project will include:

- Football data collection through APIs
- Data cleaning and feature engineering
- Exploratory data analysis
- Machine learning model development
- Model evaluation
- AWS-based data storage and deployment
- A frontend application for viewing player analytics and predictions

## Technology Stack

- Python
- Pandas
- scikit-learn
- football-data.org API
- AWS
- React / TypeScript
